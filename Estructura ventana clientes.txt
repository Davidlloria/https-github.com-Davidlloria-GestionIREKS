DIÁLOGOS Y FLUJOS RELACIONADOS
------------------------------

- Nuevo/Editar cliente: EntityDialog con el esquema de Cliente.
- Eliminar cliente: confirmación antes de borrar.
- Listados: diálogo asistido mediante CustomerReportFlowService.
- Imprimir: genera HTML del informe y usa QPrinter/QPrintDialog.
- Exportar: Listados, importación Excel/CSV y consulta del ID técnico.
- Contactos: alta y edición desde la pestaña relacionada.
- Agenda: diálogo modal para crear o editar actividad con tipo, fecha, estado,
  resumen, detalle y seguimiento; permite también eliminar.
- Ayuda: diálogo explicativo de la ventana Clientes.

RELACIÓN CON BACKEND / DATOS
----------------------------

- CustomersPage no consume el frontend React ni depende de sus componentes.
- La UI llama a CustomerService para clientes, contactos, recetas y agenda.
- CustomerService trabaja con los modelos SQLAlchemy y la base de datos local.
- Los listados usan CustomerReportIntentService, CustomerReportService,
  CustomerReportFlowService y ReportExportService.
- La selección de cliente actúa como contexto para cargar contactos, recetas y
  actividades relacionadas.
