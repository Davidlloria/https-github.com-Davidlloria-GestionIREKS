# Documentacion del repositorio

- Entorno local: `docs/setup/local-environment.md`
- Roadmap de migracion: `docs/architecture/migration-roadmap.md`

## Estructura

- `docs/architecture/`: decisiones, roadmap, historial y deuda residual.
- `docs/setup/`: arranque, entorno local, release y packaging.
- `docs/worklog/`: logs de progreso y limpieza de ramas.
- `docs/backlog/`: pendientes documentales o de recursos.
- `docs/guides/`: guias y convenciones de implementacion.
- `docs/internal/`: prompts y referencias internas de trabajo.
- `docs/ui-structure/`: estructura de ventanas PySide6/backend.
